# Session — Amazon Render QA and Seal Fix (2026-08-28)

## Decisions

- **D1** — The ChatGPT-cleaned FRONT render is approved as the base for Amazon
  slot 1 (MAIN) after passing a fine-print zoom check (CAFÉ 100% COLOMBIANO,
  NET WEIGHT 12oz/340g, tagline all faithful). Upscaled to 2000×2000 →
  `originals/amazon-main-front-2000.jpg`.
- **D2** — The BACK render's mangled seal was repaired deterministically
  (linework transplanted from the real bag photo), not regenerated by an
  image model. Result → `originals/amazon-back-seal-fixed-2000.jpg`.

## Observations

- **O1** — The ChatGPT back render corrupted the circular stamp to
  "SHALL LOT · LAND PICKĘD". Every other text block survived. Classic
  AI small-text drift; caught only at 2–3× zoom.
- **O2** — Both ChatGPT renders arrived at 1254×1254 — below Amazon's
  1600px zoom threshold; upscale is mandatory regardless of quality.
- **O3** — Real-photo cutouts (rembg u2net) of the matte black bag against
  textured stone masked cleanly; matte-on-gray was expected to be hard
  and wasn't.

## Learnings

- **L1** — Fine-print zoom inspection is a mandatory QA gate for any
  AI-cleaned product image before listing use. The failure mode is
  quiet and looks perfect at thumbnail size.
- **L2** — Replicate MCP predictions cannot carry large base64 data-URI
  inputs through tool calls (transport bottleneck, not model limits).
  Inputs must be tiny (<~20KB) or already at a public URL. Two failed
  attempts before rerouting.
- **L3** — The deterministic fix beat the generative one: extract stroke
  alpha (high-pass luminance) from the real photo, recolor to sampled
  label gold (209,150,109), erase old seal with a fitted background
  plane + matched noise, composite. Fully re-rollable from sources.

## Constraints

- **C1** — Amazon main image: pure white background, product ≥85% of
  frame, ≥1600px (2000×2000 target), no text/props on slot 1.

## Opens

- **O-open P1** — Which bag is the current production label: matte or
  glossy finish? Every listing slot should use the production one.
  (Asked; unanswered this session.)
- **O-open P2** — Slots 2, 4–7 of the 7-slot Amazon stack remain
  unbuilt; slot 3 (The Blend) can now build on the fixed back render.
- **O-open P3** — Seal sprig in the fixed back render carries slight
  hand-stamped roughness vs. the vector-clean render. Acceptable for
  listing; upstream fix is re-exporting label art if Tata wants it
  perfect.

## Deliverables

- `originals/amazon-main-front-2000.jpg` — slot 1 MAIN, 2000×2000, white bg
- `originals/amazon-back-seal-fixed-2000.jpg` — corrected back render,
  2000×2000, base for slot 3
