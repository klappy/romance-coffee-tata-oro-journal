# Session — 50/50 Split, Zoom Proposal & Repo Creation (2026-06-02)

## Decisions

1. **50/50 production split:** 50 bags ground (pour-over/fine-drip spec) + 50 bags whole bean
   - Rationale: Personal consumption benefits from whole bean for freshness and ritual grinding; ground half used first
   - Instagram poll (~78/22) informed audience preference but personal needs shifted the split
2. **CC payment preferred** for the invoice if available
3. **Repo created** as canonical, persistent, versioned project home — oddkit-indexed with YAML frontmatter

## Observations

- Shelf-life concern for ground specialty coffee (peak 1–2 weeks) mitigated by using ground half first and storing whole bean longer
- 50/50 is balanced and practical at production scale
